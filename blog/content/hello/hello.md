# Proqramlaşdırmaya Yenidən Başlayıram

Salam, necəsiz?

Proqramlaşdırmaya ilk dəfə bir neçə il əvvəl başladım. 2023 və 2024-cü illərdə HTML, CSS, JavaScript, jQuery, AJAX və Bootstrap öyrəndim. Həmin dövrdə əsas istiqamətim frontend proqramlaşdırma idi və müxtəlif kiçik layihələr hazırlayaraq praktika edirdim.

Sonra təhsil və digər səbəblərə görə proqramlaşdırmadan uzaqlaşdım. Təxminən iki və ya üç il ərzində əvvəlki tempdə kod yazmadım. Bu müddətdən sonra proqramlaşdırmaya qayıtmaq qərarına gəldim və yenidən sıfırdan sistemli şəkildə öyrənməyə başladım.

Frontend tərəfdə artıq müəyyən təcrübəm olsa da, uzun müddət yalnız frontend istiqamətində davam etmək istəmədiyimi başa düşdüm. Buna görə əsas istiqamətimi backend proqramlaşdırmaya çevirdim və Java öyrənməyə başladım.

İndi məqsədim Java əsaslarını möhkəm öyrənmək, daha sonra Spring Boot ilə real backend tətbiqləri hazırlamaq, REST API, verilənlər bazası, Git və backend layihələrinin əsas prinsiplərini mənimsəməkdir.

Bu bloqu da məhz bu proses üçün yaratmışam. Öyrəndiyim mövzuları burada qeyd edəcəyəm, yazdığım kodları paylaşacağam və qarşıma çıxan problemləri sənədləşdirəcəyəm. Məqsəd hazır olduğumu göstərmək deyil, necə inkişaf etdiyimi göstərməkdir.

Bu, mənim proqramlaşdırmaya ikinci dəfə başladığım nöqtədir.
