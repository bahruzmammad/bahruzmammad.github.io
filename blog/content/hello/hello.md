# Proqramlaşdırmaya Yenidən Başlayıram

Salam, necəsiz?

Bu mənim bloqumdakı ilk yazıdır. Uzun müddətdən sonra proqramlaşdırmaya yenidən qayıtmışam və bu bloqda öyrənmə yolumu əvvəldən sona qədər qeyd etmək istəyirəm.

Proqramlaşdırmaya ilk dəfə 2023-cü ildə daha ciddi şəkildə maraq göstərməyə başladım. Həmin vaxt əsas istiqamətim frontend proqramlaşdırma idi. HTML, CSS və JavaScript ilə başladım. Daha sonra Advanced JavaScript, jQuery, AJAX və Bootstrap öyrəndim. Öyrəndiyim mövzuları sadəcə oxumaqla kifayətlənmədim və müxtəlif kiçik layihələr hazırlayaraq praktika etməyə çalışdım.

2023 və 2024-cü illərdə əsas diqqətimi frontend sahəsinə yönəltdim. Kod yazdıqca veb səhifələrin necə hazırlandığını, istifadəçi ilə tətbiq arasındakı əlaqəni və JavaScript ilə səhifələrə necə məntiq əlavə etməyin mümkün olduğunu öyrəndim. Həmin dövrdə proqramlaşdırmaya olan marağım daha da artdı və gələcəkdə bu sahədə işləmək istədiyimi başa düşdüm.

Daha sonra proqramlaşdırma ilə arama məsafə düşdü. Təhsil və gündəlik həyat səbəbindən əvvəlki kimi müntəzəm kod yaza bilmədim. Vaxt keçdikcə bəzi mövzuları unutdum və proqramlaşdırma gündəlik həyatımın əsas hissəsi olmaqdan çıxdı. Buna baxmayaraq, yenidən proqramlaşdırmaya qayıtmaq fikri həmişə qaldı.

2026-cı ildə yenidən başlamaq qərarına gəldim. Proqramlaşdırmaya qayıtdığım ilk günlərdə başa düşdüm ki, əvvəllər müəyyən təcrübəm olsa da, bir çox mövzunu yenidən nəzərdən keçirməliyəm. Buna görə bu dəfə daha sistemli şəkildə öyrənmək qərarına gəldim.

İlk mərhələdə yenidən frontend tərəfə baxdım. JavaScript, React və Next.js ilə işlədim və müxtəlif layihələr hazırladım. Bu müddətdə frontend haqqında praktiki təcrübə qazandım və istifadəçi tərəfinin necə qurulduğunu daha yaxşı başa düşdüm.

Lakin zaman keçdikcə məni daha çox tətbiqin arxasında baş verən proseslər maraqlandırmağa başladı. Server sorğunu necə qəbul edir, məlumatlar necə saxlanılır, istifadəçidən gələn məlumatlar necə emal olunur, frontend backend ilə necə əlaqə yaradır və bütün bu hissələr birlikdə necə işləyir sualları ilə daha çox maraqlanmağa başladım.

Bu səbəbdən əsas istiqamətimi backend proqramlaşdırmaya çevirdim.

Backend üçün Java öyrənməyə başladım. Hazırda əsas diqqətimi Java dilinin fundamental mövzularına yönəltmişəm. Məqsədim sintaksisi əzbərləmək deyil. Dəyişənlərin necə işlədiyini, metodların nə etdiyini, obyektlərin və istinadların necə işlədiyini, yaddaşda məlumatların necə saxlanıldığını və obyekt yönümlü proqramlaşdırmanın əsas məntiqini başa düşmək istəyirəm.

Java əsaslarını öyrəndikdən sonra Spring Boot öyrənməyə keçəcəyəm. Daha sonra REST API, SQL, verilənlər bazası, autentifikasiya, Git və real backend layihələri üzərində işləməyi planlaşdırıram. Məqsədim bütün bu texnologiyaları ayrı ayrı öyrənmək deyil. Onların real bir backend tətbiqində necə birlikdə işlədiyini başa düşməkdir.

Bu bloqu da məhz həmin proses üçün yaratmışam. Burada öyrəndiyim mövzuları mümkün qədər sadə şəkildə izah edəcəyəm. Yazdığım kodları paylaşacağam. Qarşıma çıxan səhvləri və həll etdiyim problemləri qeyd edəcəyəm. Nəyi başa düşmədiyimi və sonradan necə başa düşdüyümü də yazacağam.

Bu yazıları yalnız başqalarının oxuması üçün yazmıram. Yazmaq mənə öyrəndiyim mövzunu yenidən düşünməyə və həqiqətən başa düşüb başa düşmədiyimi yoxlamağa kömək edir. Bir mövzunu sadə şəkildə izah edə bilmək həmin mövzunu sadəcə oxumaqdan daha yaxşı başa düşməyi tələb edir.

Zaman keçdikcə bu bloqdakı yazılar mənim proqramlaşdırma yolumun bir tarixçəsinə çevriləcək. Bu gün Java əsaslarını öyrəndiyim mərhələdən başlayaraq gələcəkdə hansı mövzulara çatdığımı, hansı layihələri hazırladığımı və hansı problemlərlə qarşılaşdığımı burada qeyd edəcəyəm.

Hazırda yolun başlanğıcındayam. Haradan başladığımı bilirəm, amma bu yolun məni hara aparacağını əvvəlcədən bilmirəm.

Bu yazı isə həmin yolun ilk səhifəsidir.
