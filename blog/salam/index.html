Salam, necəsiz?

Proqramlaşdırmaya necə başladığımı, fasilədən sonra niyə geri qayıtdığımı və Java backend istiqamətini necə seçdiyimi yazıram.

Salam, necəsiz?

Bu mənim bloqumdakı ilk yazıdır. Uzun müddətdən sonra proqramlaşdırmaya yenidən qayıtmışam və bu bloqda öyrənmə yolumu əvvəldən sona qədər qeyd etmək istəyirəm.

Proqramlaşdırmaya ilk dəfə 2023-cü ildə daha ciddi şəkildə maraq göstərməyə başladım. Həmin vaxt əsas istiqamətim frontend proqramlaşdırma idi. HTML, CSS və JavaScript ilə başladım. Daha sonra JavaScript, jQuery, AJAX və Bootstrap üzrə daha çox öyrənməyə başladım. Öyrəndikcə sadə səhifələr hazırlayır, yazdığım kodu sınayır və kiçik layihələr üzərində işləyirdim.

Həmin dövrdə proqramlaşdırmanı yalnız öyrənilməsi lazım olan bir mövzu kimi görmürdüm. Kod yazdıqca yeni bir şey qurmağın və yazdığım kodun işlədiyini görməyin özü mənə maraqlı gəlirdi. Buna görə frontend sahəsində daha çox inkişaf etmək və real layihələr hazırlamaq istəyirdim.

2023 və 2024-cü illərdə bu istiqamətdə davam etdim. Sonra təhsil və gündəlik həyat səbəbindən proqramlaşdırmaya əvvəlki qədər vaxt ayıra bilmədim. Müəyyən müddət kod yazmadım və zaman keçdikcə əvvəl öyrəndiyim bəzi mövzular zəiflədi.

2026-cı ildə yenidən proqramlaşdırmaya qayıtmaq qərarına gəldim. Bu dəfə əvvəl etdiyim kimi müxtəlif texnologiyalar arasında dağılmaq əvəzinə daha konkret istiqamət seçmək istədim. Frontend haqqında müəyyən təcrübəm olduğu üçün diqqətimi tətbiqlərin arxasında işləyən hissəyə yönəltdim.

Beləliklə Java backend istiqamətində öyrənməyə başladım. Hazırda Java əsaslarını öyrənirəm və məqsədim dili sadəcə istifadə etməyi deyil, necə işlədiyini də başa düşməkdir.

Bu bloqda da həmin yolun hər mərhələsini qeyd edəcəyəm. Öyrəndiyim mövzuları, yazdığım kodları, qarşıma çıxan problemləri və zamanla qazandığım təcrübəni burada paylaşacağam.

Hazırda yolun başlanğıcındayam. Bu yazı isə həmin başlanğıcın ilk qeydidır.
